# Machine Learning Lab

A collection of small, practical Machine Learning projects built while learning and applying core Machine Learning concepts.

This repository is mainly focused on hands-on practice. Each project applies a specific concept or technique that I have learned during my Machine Learning journey.

## Projects

### Regression

#### Car Price Prediction

A regression project that predicts car prices using Lasso Regression.

#### Customer Spending Prediction

A regression project that predicts customer yearly spending using Lasso Regression.


### Classification

#### Email Spam Classification

A classification project that predicts whether an email is Spam or Not Spam using Multinomial Naive Bayes.

#### Gender Prediction

A classification project that predicts gender using Random Forest Classifier.
